# AI PLANT CARE
1. Unzip the folder and open index.html (Chrome, Edge, Safari or Firefox).
2. Settings: choose your language, paste your own free Google Gemini API key (aistudio.google.com/apikey), tap Save.
3. Library (English), Tips, Tools and My crops work offline. Photo diagnosis, Ask, Community answers, crop plans and library translation need the key + internet. Weather needs internet + location.

Languages (whole app UI + AI answers): English, Tamil, Hindi, Telugu, Kannada, Malayalam, Marathi, Bengali.
No API key is bundled in the code. Never put a key inside the app files if you host it publicly.
Host on Netlify / GitHub Pages to use on a phone (needs https for camera/location).
